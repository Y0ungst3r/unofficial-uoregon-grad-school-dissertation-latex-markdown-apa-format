\section{Sagitta}
\label{sec:sagitta}
	The sagitta is defined as an arcs deviation from a circle. See figure that doesn't exsist yet. 
	
	The sagitta can be related to important values as 
	\begin{equation}
		(R - s)^2 + L^2 = R^2
	\end{equation}
	
	Now with some gentle work 
	\begin{equation}
		s = R\left(1 - \sqrt{1 - \frac{L^2}{R^2}}\right) 
	\end{equation}
	
	Noting that $L<<R$ for all particles that we care about we can expand to get 
	\begin{equation}
		s = \frac{L^2}{8R} \label{Sagitta}
	\end{equation}
	
	With this we can get the value for $P_t$ as 
	\begin{equation}
		P_t cos (\lambda) = .3 B R = \frac{.3 B L^2}{8 s} \label{Momentum}
	\end{equation}
	
	Where B is defined as the uniform magnetic field the particle is passing through in units of Tesla. L is the lever arm length in units of meters. s is the Sagitta as defined above in units of meters. More on this equation can be found at \url{https://pdg.lbl.gov/2024/reviews/experimental_methods_and_colliders.html}
	\subsection{Momentum Error}
	
	Momentum error can be found by starting with equation \ref{Momentum}. 
	
	\begin{equation}
		P = .3 B R \rightarrow  \delta_P = .3 B \delta_R
	\end{equation}
	
	Which dividing by P on both sides and using \ref{Momentum} again we return to.


	\begin{equation}
		 \frac{\delta_P}{P} = \frac{\delta_R}{R} \label{LinearError}
	\end{equation}
	
	Now we can find the relation for $\delta_R$ by using \ref{Sagitta}
	
	\begin{equation}
		 \delta_R = \sqrt{\left(\frac{1}{4} \frac{L^2}{s}\right)^2 \sigma_L^2 + \left( \frac{1}{8} \frac{L^2}{s^2} \right)^2 \sigma^2_s}
	\end{equation}
	
	For some reason I have yet to understand we can assume the first term in the square root is small. I am not sure I understand why. If anything I would expect them to actually be the same term. However, if it is small we return the equation that is used. 
	
		\begin{equation}
			\delta_R = \left( \frac{1}{8} \frac{L^2}{s^2} \right) \sigma_s
		\end{equation}
		
		Then we use equation \ref{LinearError} change back to the important thing. 
		
		\begin{equation}
			\frac{\delta_P}{P} = \frac{1}{8} \frac{L^2}{R s^2} \sigma_s
		\end{equation}
		
		We can remove the s with equation \ref{Sagitta}.
		
		\begin{equation}
			\frac{\delta_P}{P} = \frac{8 R}{ L^2} \sigma_s
		\end{equation}
	
		Then finally using equation \ref{Momentum} to return to all observable. 
			
	\begin{equation}
		\frac{\delta_P}{P^2} = \frac{8}{0.3 B L^2} \sigma_s
		\label{eq:pT_error}
	\end{equation}

\section{Vertex Updater}
\label{sec:KVU}

Given from Eq. \ref{eq:pT_error} that the error on the momentum measurement error goes as $L^{-2}$, one of the best ways to imporeve momentum error is to increase the measured arm. To accomplish this task for disappearing tracks we make the assumption that the tracklet comes from the nearest vertex. This process procedes as folows. 
\begin{itemize}
	\item Tracklets are reconstructed as normal
	\item The distance between each tracklet and the nearest vertex, including pileup vertices, is calculated.
	\item The tracklet is refitted assuming that the tragecticry originated from the nearest calculated vertex. 
	\item Finally the tracklet perigee parameters are updated with the new fit results. Noting that the impact parameters are identically zero. 
\end{itemize}

This method of reconstructing the momentum gains approximately an additional 33mm of length to the cord length, L. As this results in better agreement with true particle momentums it is used in this thesis in all places pT is meantioned unless specifcally noted.

	\subsection{Small number of collisions}
	Due to the statistical nature of the Ionization of particles the actual energy transferred and the actual number of collisions is different from the expected value. To calculate this some assumptions are necessary. First lets assume that the sample is thin enough that the total energy of the particle is not effected largely by the ionization. That is that $ \bar{\Delta \text{E}} << \text{E} $. 
	
	Lets also assume that there is no rare total transfer of energy. This is really more of hard elestic scattering. 
	
	The number of collisions is given by $\bar{\text{N}} = x \frac{d\text{N}}{dx}$
	
	Then the number of N collisions happening is independent of each other so it is given by the poission distribution 
	
	\begin{equation}
		P(x, \text{N}) = \frac{\bar{\text{N}}^{\text{N}}}{\text{N}!} e^{-\bar{\text{N}}}
	\end{equation}
	
	So that is N events happening has a chance P with a mean of $\bar{\text{N}}$.
	
	Now the probability density $W_1$ of an energy loss $\omega$ occurring in a single collision with an atom is. 
	
	\begin{equation}
		W_1 (\omega) = \frac{d^2\bar{\text{N}}}{dxd\omega} / \frac{d\bar{\text{N}}}{dx} = 1/ \sigma \frac{d \sigma}{d \omega}
	\end{equation}
	
	where the integral $\int_{0}^{\infty} W_1 d \omega = 1$
	
	
	Now in the case of N collisions the result is a convolution over $\omega$. 
	\begin{equation}
		W_\text{N}(\omega) = W_1(\omega)*W_1(\omega)*.....*W_1(\omega)
	\end{equation}
	
	Where the convolution is 
	\begin{equation}
		W_1(\omega)*W_1(\omega) = \int_0^\omega W_1(\omega')*W_1(\omega - \omega') d \omega'
	\end{equation}
	
	
	Now if $N = 0$ we have a special case. This is when there is no collisions so that means there can be no momentum transfer. The result of this is a function that is 0 everywhere except at $\omega = 0$ and integrates to one. 
	
	\begin{equation}
		W_0(\omega) = \delta (\omega)
	\end{equation}
	
	With this we can get our probability 
	\begin{equation}
		f(x, \Delta) = \sum_{\text{N}=0}^{\infty}\frac{\bar{\text{N}}^{\text{N}}}{\text{N}!} e^{-\bar{\text{N}}} W_\text{N}(\Delta)
	\end{equation}
	
	This ends the small number of collisions. If $\bar{\text{N}}$ is close to one then this expansion is the way to go as $W_\text{N}$ quickly goes to zero resulting in few terms being needed.
	
	\subsection{Laundau} 
	Next Landau method. This method is valid for higher number of collisions. Starting with a univariable transport equation
	
	\begin{equation}
		\Partial{f(x, \Delta)}{x} = \int_0^{T_0} w(\omega, \gamma) [f(x, \Delta - \omega) - f(x, \Delta)] d \omega
	\end{equation}
	
	With the initial condition that if the thickness is zero $f(x = 0, \Delta) = \gamma(\Delta)$. Not sure how you can have energy transfer in no thickness but okay.
	\begin{equation}
		w(\omega) = \bar{\text{N}} W_1(\omega) = x \frac{d^2 \bar{\text{N}}}{dx d \omega} = x n_a \frac{d \sigma}{d \omega}
	\end{equation}
	
	Where $w(\omega)$ is the probability of energy loss $\omega$ of a particle per unit path 
	
	This monster can be solved with a laplace transform. 
	
	\begin{equation}
		L(f(x, \Delta)) \equiv \int_{0}^{\infty} f(x, \Delta) e^{-p\Delta} d \Delta = e^{-G(x, p)}
	\end{equation}

	From this taking inspriration from someone way smarter then me I can see that 
	\begin{equation}
		G(x, p) = \int_{0}^{T_0} w(\omega)\left[ 1 - e^{-p\omega} \right] d\omega
	\end{equation}

	Which then appling the inverse laplace transform we obtain
\begin{equation}
	f(x, \Delta) = \frac{1}{2 \pi i} \int_{i \infty}^{-i \infty} \left[ e^{p \Delta - G(x, p)} \right] dp
	\label{eq:exact_dEdx}
\end{equation}

Eq. \ref{eq:exact_dEdx} is an exact solution but in practice is difficult to work with and weakly converges. Leading to a need for some assumptions to get an easier equation.
